# Scripts de desenvolvimento

- `dev-server.py`: servidor local sem cache, executado a partir da raiz do projeto.
- `gerar-catalogo.py`, `gerar-poderes.py` e `gerar-rituais.py`: validam fontes privadas e geram seeds.
- `gerar-bestiario.py`: prepara o lote privado de fichas a partir dos PDFs locais.

Os comandos e pré-requisitos estão documentados no [`README.md`](../README.md) principal.
